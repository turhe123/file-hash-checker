How it works

  1. Drop a file or type text. Pick one or many files, or switch to the Text tab. The file is read on your device in small slices, so even a multi-gigabyte image works.
  2. Read the hashes. MD5, SHA-1, SHA-256, SHA-384 and SHA-512 appear together, each with a copy button, in hex or Base64.
  3. Paste the published hash. The Compare field checks it against every result and tells you which algorithm matched. Save all results as checksums.txt or a CSV.

Questions, answered

Are my files uploaded anywhere?

No. File Hash and Checksum Calculator runs entirely in your browser. Your files are read in slices on your device, hashed with JavaScript in a background worker, and never sent to a server. That matters most when you are checking a download you do not trust yet. You can disconnect from the internet and it keeps working.

Why does my text hash not match the one from the command line?

Almost always a newline. echo abc | sha256sum hashes "abc" plus a line break, which gives a different result from "abc" alone. Tick "Include a trailing newline" on the Text tab to match echo, or use printf on the command line. Text is hashed as UTF-8 bytes.

Are MD5 and SHA-1 still safe to use?

Not for security. Both are broken: an attacker can build two different files with the same MD5 or SHA-1. If a publisher lists SHA-256 or SHA-512, compare against that. MD5 and SHA-1 are still fine for catching accidental corruption, such as a truncated download or a bad copy to a USB stick.

Does it work offline?

Yes. After your first visit the page is cached by a service worker, so it loads without a connection. You can also install it from your browser's menu as an app. Very large files on phones can run into memory limits, so a computer is the better choice for multi-gigabyte images.
